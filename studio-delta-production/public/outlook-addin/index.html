Save a Correspondance link

Do not attach a file. Paste any file link or path — including those with a lot of //. The enquiry stores it on the server as Correspondance link.

  1. Open the enquiry → Save email from Outlook or Assign costing.
  2. Paste the file link into Correspondance link.
  3. Click Save update.
  4. On Files the name is Correspondance link. Use Copy link or Open.

The Outlook add-in also saves a link only — nothing is downloaded.
