Save Outlook emails as a link

Do not attach the .msg file. The enquiry stores a link to Outlook or to this server.

  1. Open the enquiry → Save email from Outlook.
  2. Paste the Outlook link (or the Studio Delta file link) into Email link.
  3. Click Save update.
  4. On Files, use Copy link to put the server URL into an email instead of attaching the message.

The Outlook add-in also saves a link only — nothing is downloaded.
