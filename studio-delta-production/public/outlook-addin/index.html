Save emails from Outlook

Studio Delta does not download or store .msg files. The email stays in Outlook. The app keeps a link so Open in Outlook launches Outlook desktop.

Install the button once on this PC:

  1. In Outlook, open any email.
  2. Choose Get Add-ins (or File → Manage Add-ins).
  3. Open My add-ins → Add a custom add-in → Add from URL.
  4. Paste this URL:

Then open the enquiry email in Outlook, click Studio Delta on the ribbon, pick the enquiry, and save. Nothing is downloaded.
