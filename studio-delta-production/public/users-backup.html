Archive

A complete .tgz is written every night at 02:00 Johannesburg and when you click Backup now. That file packs everything the shop writes on the Railway volume: SQLite (orders, enquiries, users, production logs, schedule, rates, to-order lists, payments), JSON sidecars, quotes, drawings, proofs of payment, paint and glass invoices, job cards and images, glass PDF images, showroom bookings, email-reply templates, and the Home floor layout. It is opened and integrity-checked before it is kept.

Turn on Google Drive

Drive is not a switch in this app. Set it on the Railway service → Variables. Until those exist, Backup now still saves on this disk and says “Drive not uploaded”.

  1. Keep GOOGLE_SERVICE_ACCOUNT_JSON — the same service-account JSON used for QC PDFs. Open it and copy client_email (it ends in .iam.gserviceaccount.com).
  2. In Google Drive, create a folder such as Studio Delta ERP backups.
  3. Share that folder with the client_email as Editor (not Viewer).
  4. Open the folder. The URL looks like https://drive.google.com/drive/folders/THIS_PART. Put THIS_PART on Railway as BACKUP_DRIVE_FOLDER_ID.
  5. Optional: BACKUP_EMAIL or GMAIL_SENDER so a “backup OK” mail goes out.
  6. Wait for Railway to pick up the variables, then click Backup now. Success must say sent to Google Drive. /health should show backupOffsite: true.

QC photos taken on the tablet go into Google Docs. They are not files on this volume, so they are not inside the .tgz. Everything under /app/data is.

Restore

Restore replaces the live shop. It is not on People, and it will not run from a logged-in session alone. Type RESTORE, then enter the Manager access code twice. Upload a complete .tgz (from this page or from Google Drive) to put every file back.
